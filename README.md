# choitto-chagok-storage
최또의 차곡창고 Windows 배포 패키지

## 업데이트

v1.4.0부터 프로그램을 실행할 때 이 저장소의 최신 GitHub Release를 확인합니다.
새 버전이 있으면 업데이트 내용과 함께 설치 안내 창이 자동으로 표시됩니다.

릴리스에는 다음 파일을 첨부합니다.

- `choiagain-storage-v1.4.2.exe`: 자동 업데이트 및 설치용 셋업 파일
- `choitto-chagok-v1.4.2.zip`: 압축을 풀고 바로 실행할 수 있는 휴대용 패키지

v1.4.2부터 자동 업데이트는 `choiagain-storage`로 시작하는 EXE만 설치 파일로 인식합니다.
