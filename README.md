# choitto-chagok-storage
최또의 차곡창고 Windows 배포 패키지

## 업데이트

v1.4.0부터 프로그램을 실행할 때 이 저장소의 최신 GitHub Release를 확인합니다.
새 버전이 있으면 업데이트 내용과 함께 설치 안내 창이 자동으로 표시됩니다.

릴리스에는 다음 파일을 첨부합니다.

- `choiagain-storage-v1.5.11.exe`: 콘솔 없이 실행되는 GUI 설치 마법사
- `choitto-chagok-v1.5.11.zip`: 압축을 풀고 바로 실행할 수 있는 휴대용 패키지

v1.4.2부터 자동 업데이트는 `choiagain-storage`로 시작하는 EXE만 설치 파일로 인식합니다.

## v1.5.11

- v1.5.10에서 일반 채팅 수집이 중단되던 문제를 긴급 복구했습니다.
- 문제가 된 `ENTER_INFO` 전송 변경을 제거하고 정상 수집되던 v1.5.9 연결 방식으로 되돌렸습니다.

## v1.5.10

- 인증 채팅 연결에서 JOIN 응답 후 누락됐던 `ENTER_INFO(0012)` 패킷 전송을 추가했습니다.
- 서버가 `CHUSER_EXTEND(0127)` 구독 등급 목록을 보내도록 연결 절차를 수정했습니다.
- 진단 로그에서 모든 구독자의 확장 상태가 `missing`이던 근본 원인을 수정했습니다.

## v1.5.9

- 실제 SOOP 구독 플러스 판별값 확인을 위한 최소 진단 로그를 추가했습니다.
- 채팅 내용·닉네임·쿠키는 기록하지 않으며 사용자 ID, 숫자 등급 필드와 최종 판정만 기록합니다.
- 로그 위치: `%LOCALAPPDATA%\최또의 차곡창고\chat-grade.log`

## v1.5.8

- 원본 `CHUSER_EXTEND(127)` 패킷에 프로토콜 헤더가 포함된 점을 반영해 사용자 상태 쌍의 시작 위치를 수정했습니다.
- 실제 배열 구조인 `헤더 → 채팅방 번호 → 사용자 ID → fw/afw 상태`에 맞춰 구독 플러스 사용자를 판별합니다.

## v1.5.7

- SOOP의 `CHUSER_EXTEND(127)` 사용자 상태를 `(아이디, fw/afw)` 쌍으로 정확히 해석하도록 수정했습니다.
- `fw=3`인 구독 플러스 사용자를 `진또바기`로 분류합니다.
- 사용자 상태가 채팅보다 늦게 도착해도 기존 `또바기` 판정을 `진또바기`로 즉시 갱신합니다.
- 첫 구독자 채팅에 짧은 판정 유예를 적용해 패킷 도착 순서에 따른 오분류를 방지합니다.

## v1.5.6

- 일반 채팅 등급 명칭을 `구독자 → 또바기`, `구플 → 진또바기`, `열혈 → 남편후보`로 변경했습니다.
- 등급 판정 및 차등 공 개수 동작은 기존과 동일하게 유지됩니다.
- 5분 이상 지난 업데이트 임시 EXE와 미완료 다운로드 파일을 실행 시 자동 정리합니다.

## v1.5.5

- Google 시트 내보내기 성공 문구를 `데이터 내보내기 완료`로 통일했습니다.

## v1.5.4

- Google 시트에 데이터가 저장됐는데도 `내보내기 실패`로 표시되던 문제를 수정했습니다.
- `ok`, `success`, `saved`, `status` 등 웹 앱의 여러 성공 응답 형식을 지원합니다.
- `저장 완료` 메시지를 성공으로 처리하되 실패·오류 문구는 성공으로 오인하지 않습니다.

## v1.5.3

- GitHub 브라우저 다운로드 URL에서 HTTP 504가 발생하던 원인을 확인했습니다.
- 업데이트 다운로드를 GitHub 릴리스 자산 API 방식으로 변경했습니다.
- 일시적인 네트워크 오류 및 5xx 응답에 최대 4회 재시도합니다.
- 실패 원인과 시각을 `%LOCALAPPDATA%\최또의 차곡창고\update.log`에 기록합니다.
- v1.4.2 사용자의 전환을 위해 새 JAR만 설치하는 소형 `choiagain-storage.exe`를 함께 제공합니다.

## v1.5.2

- 버전이 포함된 `choiagain-storage-v버전.exe` 설치 파일을 자동 업데이트가 찾지 못하던 문제를 수정했습니다.
- 기존 버전의 자동 업데이트를 위해 릴리스에 `choiagain-storage.exe` 호환 파일도 제공합니다.

## v1.5.1

- `모두 지우기` 확인창이 작게 표시되어 본문과 버튼이 보이지 않던 문제를 수정했습니다.
- 확인창에 안내 문구와 `취소`, `확인` 버튼이 항상 표시되도록 전용 창으로 교체했습니다.

## v1.5.0

- 일반 채팅 등급에 `구플`(구독 플러스)을 추가했습니다.
- 일반 구독자와 구독 플러스 이용자를 분리해 수집합니다.
- `차등 수집` ON/OFF 기능을 추가했습니다.
- 차등 수집이 켜지면 건빵·팬·구독자·구플·열혈별 공 개수를 직접 설정할 수 있습니다.
- 기본 차등값은 건빵 1, 팬 2, 구독자 3, 구플 4, 열혈 5입니다.
